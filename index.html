How to install
This is an Android app. Open this page on the Android phone you will sell from, then tap Install. Bn needs a real phone because it dials USSD codes and reads SMS, which a website or an iPhone cannot do.

Step by step

Install in 4 steps

Takes about two minutes. Do this on the phone you will use for selling.

  1. Tap Install BnThe file Bn.apk downloads to your phone. If Chrome says "This type of file can harm your device", choose Download anyway. Bn is not on the Play Store, so Android always shows this warning.
  2. Open the file and allow the installTap Open on the download. If Android says your phone is not allowed to install unknown apps from this source, tap Settings, turn on Allow from this source, go back and tap Install. If Play Protect warns about an unknown app, tap More details → Install anyway.
  3. Open Bn and allow what it asks forBn walks you through it one step at a time: Phone, SMS and Notifications. Tap Allow each time.
  4. Turn on the helper and check the top of the appSwitch on Bn under Settings → Accessibility, and set battery to Don't optimise. When the top of Bn says Connected, you are ready.
Permissions greyed out, or "Restricted setting"?
Android 13 and newer blocks some permissions for apps installed from a file. Go to Settings → Apps → Bn, tap the ⋮ menu at the top right, choose Allow restricted settings, then open Bn again.
Updating later?
Install the new Bn.apk over the old one. Your sales, offers, settings and permissions are kept. Do not uninstall first.
Setup guide, daily use & help

Overview

How Bn works

Once it is set up, a sale needs no tapping from you.

Customer paysAn M-Pesa message arrives on your phone.
Bn matches itThe amount is matched to one of your offers.
Bn dialsIt runs the code and sends each menu step for you.
Safaricom confirmsThe sale shows as Success. If no confirmation comes in time, it shows as Failed so you can retry.
Customer is toldBn texts them that the offer was renewed.

Daily use

Using Bn every day

Five tabs along the bottom of the app.

HomeToday's, this week's and this month's sales, your profit, a 7-day chart and recent activity.
SalesFilter by All, Live (in progress), Success or Failed. Retry a failed sale with one tap.
OffersYour Normal and Advanced offers. Calibrate advanced ones here. A badge shows if one was paused.
TeamOwner only. Let attendants sign in with their own accounts (needs the optional Firebase setup).
SettingsFour tabs: General, Dialing, Texts and Phone (helper, screen off, activity log).
Good habits
Keep the phone charged and the screen set to stay on. Keep enough airtime for the codes and customer texts. Check the Live filter if a customer says they have not received their bundle, and calibrate your advanced offers whenever Safaricom updates its menus.

Support

Help

Common problems and quick fixes.

The top of Bn does not say Connected

Open Settings → Accessibility and make sure Bn is switched on. Then open Bn → Settings → Phone → Restart helper now.

Bn skips steps or sends the wrong menu number

Your phone is probably slow. Go to Settings → Dialing and set Dialing speed to Careful.

A sale shows Failed but the customer got the bundle

Safaricom's confirmation message arrived late or did not match. Raise the Confirmation wait minutes in Settings → Dialing, and check the sale before retrying so you do not sell twice.

Customers get a text saying the number was already recommended

Safaricom allows one recommendation per number per day. Bn tells the customer to send a different number. You can change the wording in Settings → Texts.

An offer switched itself off

Calibration paused it because Safaricom's menu changed or the check failed. Open Offers → Advanced, tap Review to see the menu, then Looks right if it is correct, or fix the code and calibrate again.

Will it work on an iPhone or in a browser?

No. Dialing USSD codes and reading SMS needs the Android app.

Is my data safe when I update?

Yes. Install the new file over the old app and everything is kept. If you uninstall Bn first, your data and the optional helper setup are lost.
